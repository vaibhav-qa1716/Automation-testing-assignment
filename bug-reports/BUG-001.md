# BUG-001: First Name field accepts numeric values

**Module:** Checkout Information  
**Field:** First Name  
**Test Account:** standard_user  
**Test Data:** 41  
**Severity:** To be assessed

### Preconditions
- User is logged in.
- At least one product is added to the cart.

### Steps to Reproduce
1. Navigate to the cart.
2. Click Checkout.
3. Enter `41` in First Name.
4. Enter valid Last Name and Postal Code.
5. Click Continue.

### Expected Result
If the requirement specifies alphabetic names only, numeric values should be rejected with a validation message.

### Actual Result
The application accepts `41` in the First Name field.
