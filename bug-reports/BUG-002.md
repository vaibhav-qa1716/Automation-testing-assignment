# BUG-002: Postal Code field accepts alphabetic values

**Module:** Checkout Information  
**Field:** Postal Code  
**Test Account:** standard_user  
**Test Data:** xyz 
**Severity:** To be assessed

### Preconditions
- User is logged in.
- At least one product is added to the cart.

### Steps to Reproduce
1. Navigate to the cart.
2. Click Checkout.
3. Enter a valid First Name.
4. Enter a valid Last Name.
5. Enter `xyz` in Postal Code.
6. Click Continue.

### Expected Result
If the requirement specifies numeric postal codes only, alphabetic values should be rejected with an appropriate validation message.

### Actual Result
The application accepts alphabetic characters in the Postal Code field.
