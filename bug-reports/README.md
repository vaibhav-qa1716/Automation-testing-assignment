# Bug investigation and reports

The assignment requires at least two **real, reproducible** defects on Sauce Demo. Do not submit an unverified hypothesis as a confirmed bug.

## Investigation procedure
1. Open https://www.saucedemo.com/ and use the test accounts listed on its login page.
2. Explore login, inventory, product details, cart, checkout and logout.
3. Repeat any unexpected behavior in a fresh browser session.
4. Capture a screenshot or short recording and note browser, date/time and account type (do not record passwords).
5. Check whether the behavior is expected for a special test account (for example, `problem_user` may intentionally demonstrate defects).
6. Only then complete a report below.
